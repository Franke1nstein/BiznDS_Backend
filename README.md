## Intro to the Project

This is the backend for the [ecommerce-project](https://github.com/Franke1nstein/BiznDS).

Most part of the code was generated with AI.

## Set up this backend

1. Make sure you have NodeJS installed (version 22+). If not, [click here to install](https://nodejs.org/).
2. Unzip the code. On Windows, right-click the zip file > `Extract All`. On Mac, double-click the zip file.
3. Open this code in VSCode.
4. At the top menu of VSCode, click `Terminal` > `New Terminal`.
5. In the Terminal, run `npm install`, and run `npm run dev`.
